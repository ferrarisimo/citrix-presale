# citrix-presale

Web app presale con interfaccia moderna per un robot AI dedicato a Citrix.

## Funzionalità
- Chat assistita per rispondere a richieste cliente su tematiche Citrix.
- Sezione **Library Knowledge** per caricare documenti (`.txt`, `.md`, `.json`) che diventano base informativa del robot.
- Risposte orientate anche alla promozione del valore di prodotto Citrix.
- Persistenza locale della library tramite `localStorage`.

## Avvio locale
Apri `index.html` direttamente nel browser oppure avvia un server statico:

```bash
python3 -m http.server 4173
```

Poi visita `http://localhost:4173`.
